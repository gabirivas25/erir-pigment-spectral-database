# Thesis tables and appendices (Word files)

The tables and appendices written for the thesis "From Mineral Standards to Museum Walls", as Word files in the table style of the thesis (heavy rule above and below, bold header, light grey rules between rows, no vertical lines, Times New Roman). Table numbers marked X are placeholders until the final numbering.

| File | Content |
|---|---|
| `Table_2.X_database_comparison.docx` | Comparison of the spectral databases (IRUG, INFRA-ART, FORS / Pigments Checker, Bulgarian database, RRUFF, Izzo et alii 2020) |
| `Table_4.5.docx` | Test 2: materials that ranked first most often, by sample and method, over ten regions |
| `Table_4.6.docx` | Test 2: materials that ranked first most often over the 15 scans, by method and region |
| `Tables_Test1_regions.docx` | Test 1, Parts 1 and 2: first place and top three by method and region |
| `Tables_4.9_4.11.docx` | Test 2: number of the 15 scans whose top material or top three changed with the 600 cm-1 grid start (4.9) and with one peak setting changed (4.11) |
| `Table_4.X_grid_start_600.docx` | Test 2: top three materials of the scans that changed when the grid started at 600 cm-1 |
| `Table_4.X_peak_settings.docx` | Test 2: top three materials with peak-position matching for the scans that changed when one peak setting changed (95 rows) |
| `Table_4.X_peak_settings_top_material.docx` | Peak settings: change of the top material |
| `Table_4.X_peak_settings_top_three.docx` | Peak settings: change of the top three materials |
| `Thesis_Appendices_A-G_draft.docx` | Appendices A to G: data dictionary, specimen manifest, matching configuration, source code, per-scan results of Test 1 and Test 2, mock-up specifications |
| `References_draft.docx` | Draft reference list. Entries marked [CHECK] could not be verified |

The appendix draft still has gaps marked "[to be completed]" (impurities and alteration products of the specimens; thickness, binder, substrate and preparation of the layered mock-ups).
